# Claude

Anthropic의 LLM. 이 vault의 환경 구축·노트 작업을 수행하는 주력 에이전트.

## 사용 형태
- **Claude Code (CLI)** — 터미널에서 파일 읽기/쓰기/명령 실행. 맥미니 셋업·git·발행을 직접 수행.
- **claude.ai** — 웹/앱 채팅.
- **MCP 연결** — 4주차 주제. Gmail·Calendar·Drive·Slack 등 도구를 표준으로 연결.
- **HTML 산출물** — spec, plan, PR explainer, report를 사람이 다시 읽고 피드백하기 좋은 인터페이스로 렌더링.

## 이 환경에서의 역할
- 맥미니 원격 작업: SSH로 들어와 명령 수행
- vault 노트 작성·인덱싱 보조
- GitHub repo 생성·배포 자동화
