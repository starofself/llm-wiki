# Codex

OpenAI의 코딩 에이전트. 터미널/IDE에서 코드 작성·실행을 돕는다. 이 환경에서는 [[claude|Claude Code]]와 함께 다중 에이전트로 활용.

## 위치
- 맥미니에 `~/.codex` 설정 존재 → 별도 코딩 에이전트로 병행 사용 중.
- Claude Code와 역할 분담: 작업 성격에 따라 선택.
