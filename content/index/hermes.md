# Hermes

기존에 사용 중인 텔레그램/디스코드 봇. 외부에서 맥미니 작업을 호출하는 입출력 채널.

## 사용 형태
- **텔레그램 봇** — 핸드폰에서 한 줄 명령 → 맥미니 처리
- **디스코드 봇** — 동일 구조, 다른 플랫폼
- 미리 정의된 명령 기반 (자연어 처리 한정적)

## 한계 (개선 방향)
- 자연어 자유도 부족 — 새로운 작업마다 명령 추가 필요
- 4주 후 그림: **텔레그램 봇이 받은 자연어를 그대로 `claude` CLI에 전달** → Claude Code가 알아서 해석
- 봇은 **입출력 채널**, 두뇌는 **Claude Code**로 분리

## 이 환경에서의 역할
- 2주차 강의 주제 — BotFather로 새 봇 만들고 vault 슬래시 커맨드 호출
- 모바일 → vault 입력 경로 확보
- 노트 작성·검색·요약을 텔레그램 한 줄로
