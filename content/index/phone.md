# 핸드폰

이 강의의 핵심 목표 — **핸드폰을 맥미니 자동화의 입력/출력 인터페이스로 만드는 것**. "밖에서 폰으로 집의 맥미니를 부린다."

## 인터페이스 4주와의 연결
- 1주차: 노트(vault) 기반 다지기
- 2주차: **텔레그램 봇** → 폰에서 메시지로 맥미니 호출
- 3주차: Tailscale + API → 폰에서 안전하게 원격 실행
- 4주차: MCP → 표준 도구 연결

## 입력/출력 채널 구상
- **입력**: 텔레그램, 음성, API 호출
- **출력**: 알림, 노트 자동 저장, 파일 동기화
