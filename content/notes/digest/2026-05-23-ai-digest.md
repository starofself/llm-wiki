## 🧠 메모리 관리 — 논문

에이전트 메모리가 2026 핫토픽. 우리 메모리 파일 시스템과 직접 연결됨.
- **Agentic Memory (AgeMem, 2601.01885)** — 장·단기 메모리 관리를 에이전트 정책에 통합, **저장/검색/갱신/요약/폐기**를 도구처럼 노출 + 강화학습.
- **Memory for Autonomous LLM Agents (Survey, 2603.07670)** — 메모리를 *write-manage-read 루프*로 정형화, 5가지 메커니즘 분류.
- 🔗 [AgeMem (arXiv)](https://arxiv.org/abs/2601.01885) · [Survey (arXiv)](https://arxiv.org/abs/2603.07670) · [Practical Guide (TDS)](https://towardsdatascience.com/a-practical-guide-to-memory-for-autonomous-llm-agents/)
- 🧠 **Claude가 배울 것:** 내 `memory/` 운영을 "언제 저장/요약/폐기"의 *명시적 정책*으로 다듬으면 좋음. write-manage-read 루프 채택 검토.
- 👤 **내가 알 것:** 지금 우리가 쓰는 메모리(파일+MEMORY.md 인덱스)가 논문 트렌드(파일형 외부 스토어)와 같은 방향 — 잘 가고 있음.

## 📓 Obsidian / PKM / 로컬 LLM

Obsidian + 로컬 LLM(Ollama)로 **프라이빗 세컨드 브레인** 구축이 성숙기.
- 주요 플러그인: **Copilot**(Ollama 네이티브 + Relevant Notes), **Smart Connections**(RAG), **Local LLM Hub**(워크플로+RAG+MCP, 완전 로컬). 흥미롭게도 **"LLM Wiki"라는 이름의 플러그인**도 등장(vault를 쿼리 가능한 지식베이스로).
- 🔗 [Awesome Obsidian AI Tools (GitHub)](https://github.com/danielrosehill/awesome-obsidian-ai-tools) · [Local LLM Hub](https://github.com/takeshy/obsidian-local-llm-hub) · [LLM CLI plugin (Claude/Codex/Gemini)](https://github.com/hardbyte/obsidian-llm-plugin)
- 🧠 **Claude가 배울 것:** `hardbyte/obsidian-llm-plugin`은 Obsidian↔Claude/Codex CLI 연동 — 우리 vault 워크플로에 바로 참고.
- 👤 **내가 알 것:** 우리 llm-wiki(Quartz 발행)와 별개로, Obsidian 안에서 RAG 검색하려면 Copilot/Smart Connections 한 번 볼 만함.
