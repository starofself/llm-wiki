## 🤖 Claude / Claude Code

**대규모 안정성·워크플로 업데이트** — 백그라운드 세션 처리 개선, MCP/SDK 시작 속도↑, 터미널 글리치·크래시·세션 복구 다수 수정.
- **원격 제어**: 한 머신에서 시작한 세션을 폰에서 이어받기. 데스크톱 GUI 리디자인(분할 뷰, 어시스턴트 메시지를 챕터로 핀 + 자동 목차, 인라인 diff 코멘트).
- 핀 고정 백그라운드 세션은 idle에도 유지되고 업데이트 적용 시 제자리 재시작. `/model`은 현재 세션만 변경(`d` 누르면 새 세션 기본값 설정).
- **5시간 한도 2배** (Pro/Max/Team/Enterprise), Pro·Max 피크타임 감축 폐지.
- 🔗 [Claude Code Changelog](https://code.claude.com/docs/en/changelog) · [Code w/ Claude 2026 라이브블로그 (Simon Willison)](https://simonwillison.net/2026/May/6/code-w-claude-2026/) · [Managed Agents·Proactive Workflows (InfoQ)](https://www.infoq.com/news/2026/05/code-with-claude/)
- 🧠 **Claude(나)가 배울 것:** "원격 제어(폰 이어받기)"가 정식 기능화 → 우리 텔레그램 브리지와 역할 겹침. 이 다이제스트도 핀 챕터+목차로 정리하면 가독성↑.
- 👤 **내가 알 것:** 5시간 한도가 또 2배 됐다. 피크타임 감축도 사라짐 → 더 빡세게 굴려도 됨.

## 🧠 메모리 관리 — 논문

에이전트 메모리가 2026 핫토픽 지속. 우리 `memory/` 파일 시스템과 직접 연결됨.
- **From Storage to Experience (2605.06716, 5/7)** — 에이전트 메모리 진화를 **Storage(궤적 보존) → Reflection(정제) → Experience(추상화)** 3단계로 정형화한 신규 서베이.
- **Memory for Autonomous LLM Agents (2603.07670)** — 메모리를 *write–manage–read 루프*로 보고, 시간범위·표현기질·제어정책 3차원 분류 제시.
- 🔗 [From Storage to Experience (arXiv)](https://arxiv.org/abs/2605.06716) · [Memory Survey (arXiv)](https://arxiv.org/abs/2603.07670) · [LTM 보안 서베이 (arXiv)](https://arxiv.org/abs/2604.16548)
- 🧠 **Claude가 배울 것:** 내 메모리를 단순 저장(Storage)에서 멈추지 말고 **Reflection→Experience** 단계로 끌어올리기 — 메모를 주기적으로 정제·추상화하는 정책 검토.
- 👤 **내가 알 것:** 우리 파일+MEMORY.md 인덱스 방식은 논문의 "외부 스토어 + 라우팅" 트렌드와 일치. 다음 단계는 "쌓기"에서 "정제"로.

## 📓 Obsidian / PKM / 로컬 LLM

**Karpathy의 "LLM Wiki" 패턴이 바이럴** (4월 글, 48시간 만에 32.5만 조회) — 우리 llm-wiki가 바로 이 패턴이다.
- 핵심: LLM이 **지식 컴파일러**로서 마크다운 위키를 점진적으로 빌드·유지. 질의 시 `index.md`가 관련 개념 페이지로 라우팅 → 모델이 선택된 페이지만 읽고 인용과 함께 답변(보통 3-read).
- Obsidian + Ollama 조합이면 완전 로컬: 노트가 집 밖으로 안 나감, 벤더 락인·구독 없음. 관리 오버헤드 30~40% → 10% 미만.
- 🔗 [Karpathy LLM Wiki + Claude Code 셋업 (Alfonso Fortunato)](https://alfonsofortunato.com/blog/obsidian-pkm-llm-wiki/) · [로컬 LLM 지식베이스 구축 가이드 (modemguides)](https://www.modemguides.com/blogs/ai-infrastructure/local-llm-knowledge-base-obsidian-setup-guide) · [LLM Wiki 플러그인 (Obsidian Forum)](https://forum.obsidian.md/t/new-plugin-llm-wiki-turn-your-vault-into-a-queryable-knowledge-base-privately/113223)
- 🧠 **Claude가 배울 것:** Karpathy식 "index.md 라우팅 → 개념페이지 → 원문" 3-read를 우리 vault에도 명시적으로 적용. 우리 index.md를 라우팅 친화적으로 유지.
- 👤 **내가 알 것:** 우리가 하고 있는 게 바로 지금 화제의 그 패턴. "LLM Wiki" 동명 플러그인도 등장 → 로컬 RAG 검색 한 번 볼 만함.
