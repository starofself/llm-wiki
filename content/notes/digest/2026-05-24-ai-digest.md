## 🟢 OpenAI / GPT

**메모리·스프레드시트로 무게중심 이동** — 어제 다룬 GPT-5.5 Instant에 이어, ChatGPT에 **"메모리 소스(memory sources)"** 컨트롤 추가: 답변 개인화에 쓴 컨텍스트(저장 메모리·과거 대화)를 사용자에게 **투명하게 노출**. 과거 대화·파일·Gmail 기반 개인화가 Plus/Pro 웹에 롤아웃.
- **ChatGPT for Excel/Google Sheets 글로벌 출시** — 사이드바에서 시트 빌드·수정·이해. Pro용 개인 재무 대시보드(미국).
- 🔗 [GPT-5.5 Instant (OpenAI)](https://openai.com/index/gpt-5-5-instant/) · [ChatGPT 릴리스노트 (OpenAI Help)](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · [GPT-5.5 정확도·이모지 (9to5Mac)](https://9to5mac.com/2026/05/05/gpt-5-5-instant-makes-chatgpt-more-accurate-while-nixing-gratuitous-emojis/)
- 🧠 **Claude가 배울 것:** "메모리 소스" = 어떤 메모를 근거로 답했는지 사용자에게 보여주는 투명성 장치. 우리 `memory/` 회상 시 "이 메모리를 참고함"을 노출하는 패턴 도입 검토.
- 👤 **내가 알 것:** 메모리 투명성이 업계 기본기로 굳는 중. hermes의 GPT 계열(Codex OAuth) 토큰 재인증은 **여전히 미처리 TODO**.

## 🧠 메모리 관리 — 논문

어제의 3편(2605.06716·2603.07670·2604.16548)에 더해, **통합 표현–관리 관점 서베이**를 추가 포착.
- **LLM Agent Memory: A Unified Representation–Management Perspective** — 메모리를 *자연어 토큰 / 중간표현 / 파라미터* 3패러다임으로 나누고, 각각을 **구축(construction)·갱신(update)·질의(query)** 3단계로 정리. (OpenReview / Preprints.org, 2026-03)
- 보안 관점: **LTM 보안 서베이(2604.16548)** — 장기기억 에이전트의 공격면·방어·아키텍처·연구공백 정리.
- 🔗 [Unified Rep–Management (OpenReview)](https://openreview.net/forum?id=KPs1EgGKcT) · [동 서베이 (Preprints.org)](https://www.preprints.org/manuscript/202603.0359/v1) · [LTM 보안 서베이 (arXiv)](https://arxiv.org/abs/2604.16548)
- 🧠 **Claude가 배울 것:** 우리 메모리는 "자연어 토큰" 패러다임(마크다운 파일). 논문 프레임의 **갱신(update) 단계**가 우리 약점 — 회상만 하지 말고 주기적 갱신·중복정리 정책 명문화.
- 👤 **내가 알 것:** LTM 보안 서베이는 "메모리 주입 공격"을 다룸 → 공개 사이트에 메모리 노출 금지 원칙(어제 IP·계정 마스킹과 같은 결)을 메모리에도 적용.
