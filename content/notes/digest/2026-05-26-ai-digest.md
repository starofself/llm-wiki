## 🤖 Claude / Claude Code

**거버넌스가 본격화** — Anthropic이 5/25 **보안·컴플라이언스 통합 28종**을 공개. DLP·SASE·SIEM·IAM·eDiscovery·AI 보안태세 관리 등 28개 프로바이더(Cloudflare, CrowdStrike, Datadog, Fortinet 등)와 연동, 거기에 **Compliance API**(Claude 활동 데이터를 REST로 조회 → 상시 모니터링·정책 자동시행)까지 붙였다.
- Claude Code 쪽은 `/usage`가 스킬·서브에이전트·플러그인·MCP 서버별 비용 분해를 보여주고, `/diff`를 키보드(j/k·PgUp/Dn)로 스크롤, 마크다운 체크박스 GFM 렌더링 추가. 엔터프라이즈용 claude.ai 클라우드 MCP 커넥터 설정도 신설.
- 🔗 [보안·컴플라이언스 통합 28종 (Help Net Security)](https://www.helpnetsecurity.com/2026/05/25/anthropic-security-compliance-integrations-claude/) · [Claude Code Changelog](https://code.claude.com/docs/en/changelog) · [Code with Claude 분석 (MIT Tech Review)](https://www.technologyreview.com/2026/05/21/1137735/anthropics-code-with-claude-showed-off-codings-future-whether-you-like-it-or-not/)
- 🧠 **Claude(나)가 배울 것:** "에이전트가 무엇을, 어떤 권한으로 했는가"의 **감사 로그**가 제품 핵심으로 올라옴. 우리 텔레그램 브리지에도 tool call 감사기록 자리를 만들어 둘 것.
- 👤 **내가 알 것:** Compliance API는 기업 IT가 Claude를 통제하는 통로. 개인 vault엔 직접 쓸 일 없지만, "활동 로그를 API로 뽑는다"는 패턴은 우리 봇 운영기록에도 응용 가능.

## 🔷 Gemini / Antigravity

**Antigravity 2.0 진통 수습 중** — 2.0 초기 롤아웃이 내장 IDE를 들어내고 휑한 챗 인터페이스로 떨궈 반발. Google이 5/23 **UI 업데이트로 "코드 에디터 안 죽었다"**를 명확히 하고 Gemini 사용량 한도를 리셋·재인상(이달에만 한도 여러 차례 상향).
- 큰 그림은 그대로: Antigravity 2.0 데스크톱 앱 + CLI + SDK로 멀티 에이전트 병렬·예약작업·서브에이전트. Gemini CLI는 **Antigravity CLI로 전환** 공식화. 엔진은 Gemini 3.5 Flash(3.1 Pro 능가 + 4배 빠름).
- 🔗 [Antigravity 2.0 UI 정정 + Gemini 한도 리셋 (PiunikaWeb)](https://piunikaweb.com/2026/05/23/google-antigravity-2-0-ide-update-gemini-quota-reset/) · [Gemini CLI → Antigravity CLI 전환 (Google Devs)](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) · [I/O 2026 개발자 하이라이트 (Google)](https://blog.google/innovation-and-ai/technology/developers-tools/google-io-2026-developer-highlights/)
- 🧠 **Claude가 배울 것:** "IDE를 통째로 에이전트 챗으로 바꿨다가 반발"은 좋은 교훈 — 자동화로 갈아탈 때도 **사용자가 쓰던 표면을 갑자기 없애지 말 것**.
- 👤 **내가 알 것:** Gemini CLI 단독 실험은 이제 Antigravity CLI 기준으로 보는 게 맞다. 우리 실습세션 노트와 [[remote-work]] 흐름에 반영.

## 🧠 메모리 관리 — 논문

에이전트 메모리가 2026 핫토픽 지속. 우리 `memory/` 파일 시스템과 직접 연결됨.
- **From Storage to Experience (2605.06716, 5/7)** — 메모리 진화를 **장기 일관성·동적환경·지속학습** 3대 동인으로 보고, 능동탐색·**교차궤적 추상화(cross-trajectory abstraction)**를 핵심 메커니즘으로 제시.
- **Memory for Autonomous LLM Agents (2603.07670)** — 메모리를 *write–manage–read 루프*로 정형화, 5대 메커니즘(컨텍스트압축·검색증강스토어·반성적 자기개선·계층가상컨텍스트·정책학습관리) 분류.
- **LTM 보안 서베이 (2604.16548)** — "기억 주권(mnemonic sovereignty)": 무엇을 쓰고·누가 읽고·언제 갱신·무엇을 잊을지를 **검증가능하게 통치**.
- 🔗 [From Storage to Experience (arXiv)](https://arxiv.org/abs/2605.06716) · [Memory Survey (arXiv)](https://arxiv.org/abs/2603.07670) · [LTM 보안 서베이 (arXiv)](https://arxiv.org/abs/2604.16548)
- 🧠 **Claude가 배울 것:** 내 메모리를 단순 적재에서 멈추지 말고 **교차궤적 추상화**로 — 여러 다이제스트를 가로질러 반복되는 패턴을 한 줄 원칙으로 정제.
- 👤 **내가 알 것:** "기억 주권" 프레임이 우리 MEMORY.md 운영과 정확히 맞다 — 보기/수정/삭제 권한을 사람이 쥔다.

## 📓 Obsidian / PKM / 로컬 LLM

**Karpathy LLM Wiki 패턴이 "운동"으로** — 작년 10월 Gist 한 장이 6개월 만에 성숙한 오픈소스 구현 5종+ 으로 번짐. 결정적으로 **Obsidian CEO가 "Claude에게 Obsidian 네이티브 문법을 가르치는 공식 스킬"을 공개**.
- 핵심은 그대로: 로컬 LLM이 **지식 컴파일러**로 마크다운 위키를 점증 빌드, `index.md` 라우팅 → 선택 페이지만 읽고 인용. Obsidian + Ollama면 완전 로컬·오프라인. qmd(BM25+벡터+LLM 리랭크) 로컬 검색도 인기.
- 🔗 [Obsidian이 개인 LLM 하니스 베이스로 승리한 이유 (Roan Monteiro, Medium)](https://medium.com/@roanmonteiro/why-obsidian-won-as-the-base-for-the-personal-llm-harness-and-when-you-shouldnt-pick-it-9790271e5313) · [Karpathy LLM Wiki + Claude Code 셋업 (Alfonso Fortunato)](https://alfonsofortunato.com/blog/obsidian-pkm-llm-wiki/) · [LLM Wiki 플러그인 (Obsidian Forum)](https://forum.obsidian.md/t/new-plugin-llm-wiki-turn-your-vault-into-a-queryable-knowledge-base-privately/113223)
- 🧠 **Claude가 배울 것:** Obsidian 공식 스킬이 나왔다 → 위키링크·임베드·프론트매터를 **네이티브로** 더 정확히 쓸 수 있게 됨. 우리 vault 작성 규칙(CLAUDE.md)과 맞물려 점검할 것.
- 👤 **내가 알 것:** 우리가 하는 게 바로 그 화제의 패턴. Obsidian 공식 Claude 스킬을 한 번 깔아볼 가치 있음.
