## 🧠 메모리 관리 — 논문

에이전트 메모리, 우리 `memory/` 파일 시스템과 직결되는 핫토픽 지속.
- **Agentic Memory / AgeMem (2601.01885)** — 장기·단기 메모리 관리를 **에이전트 정책에 직접 통합**, 메모리 연산(저장·검색·갱신·요약·폐기)을 **툴 기반 액션**으로 노출 → 무엇을 언제 기억할지 에이전트가 자율 결정.
- **Adaptive Memory Admission Control (2603.04549)** — 무엇을 메모리에 "입수(admit)"할지 적응적으로 제어하는 게이트 메커니즘. 어제 본 A-MAC 입수게이트 라인과 연결.
- 🔗 [AgeMem (arXiv)](https://arxiv.org/abs/2601.01885) · [Memory Survey (arXiv)](https://arxiv.org/abs/2603.07670) · [Admission Control (arXiv)](https://arxiv.org/pdf/2603.04549) · [SimpleMem (GitHub)](https://github.com/aiming-lab/SimpleMem)
- 🧠 **Claude가 배울 것:** AgeMem처럼 메모리 쓰기/폐기를 "명시적 결정"으로 다루기 — 지금 MEMORY.md 업데이트도 "입수 기준(admission)"을 정해두면 노이즈 누적 방지.
- 👤 **내가 알 것:** 우리 파일+인덱스 방식은 논문의 "툴 기반 메모리 액션"과 같은 방향. 다음 단계는 폐기/정제 정책 명문화.
