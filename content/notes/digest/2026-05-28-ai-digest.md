# AI 데일리 다이제스트 — 2026-05-28 (목)

## 🤖 Claude / Claude Code

**보안 플러그인 + SpaceX Colossus 1 인프라 딜** — Claude Code가 마켓플레이스에서 `/plugins`로 설치 가능한 **security-guidance** 플러그인을 정식 공개. 편집·diff·커밋을 실시간 모니터링해 SQL/명령어 인젝션, XSS, 하드코딩된 시크릿, 안전하지 않은 역직렬화 등 **약 25개 고위험 취약 클래스**를 regex 패턴매칭으로 즉시 플래그.
- `/usage`가 한도 소진 원인을 **카테고리별 내역**으로 표시, `/diff` 상세뷰를 **키보드 스크롤** 가능, 마크다운 태스크 리스트 렌더링 개선, Claude.ai 클라우드 MCP 커넥터용 엔터프라이즈 설정 추가.
- **SpaceX 데이터센터 거래**: Anthropic이 멤피스 **Colossus 1** 풀 컴퓨트(300MW+, NVIDIA GPU **22만 장 상당**) 확보.
- 🔗 [Claude Code 보안 플러그인 (Cybersecurity News)](https://cybersecuritynews.com/anthropic-updates-claude-code/) · [Claude Code Updates - Releasebot](https://releasebot.io/updates/anthropic/claude-code) · [Anthropic 릴리스](https://github.com/anthropics/claude-code/releases) · [Code with Claude 후기 (MIT Tech Review)](https://www.technologyreview.com/2026/05/21/1137735/anthropics-code-with-claude-showed-off-codings-future-whether-you-like-it-or-not/)
- 🧠 **Claude가 배울 것:** 우리도 `security-guidance`를 설치하고 다이제스트 자동화·텔레그램 봇 커밋 경로에 적용해 시크릿/토큰 누출을 자동 차단. `/usage` 카테고리별 분석으로 어디서 한도를 태우는지 한 번 점검.
- 👤 **내가 알 것:** 22만 GPU급 신규 컴퓨트 확보 → 한도/성능 더 풀릴 여지. 보안 플러그인은 vault·봇 모두에 즉시 적용 가치.

## 🔷 Gemini / Google AI Studio / Antigravity

**Antigravity 2.0 UI 혼동 정리 패치 + Gemini 한도 누적 9× 인상** — 사용자들이 2.0 데스크톱 앱과 웹 대시보드 사이에서 헷갈리던 문제를 해결하기 위해 Google이 **2.0 웹 대시보드 상단에 "Open IDE" 버튼**을 큼직하게 박는 UI 패치 배포. 동시에 Antigravity의 Gemini 사용량을 **연속 2회 3배씩 인상**해 nerf 직후 대비 **9배** 한도.
- Antigravity 2.0은 **다중 에이전트 오케스트레이션** 중심의 독립 데스크톱 앱(에이전트 다이렉팅 + 동적 서브에이전트 + 백그라운드 스케줄 태스크). Gemini 3.5 Flash가 3.1 Pro를 거의 모든 벤치에서 능가하면서 **4배 빠름**.
- 🔗 [Antigravity 2.0 UI 정정 + Gemini 쿼터 리셋 (Piunikaweb)](https://piunikaweb.com/2026/05/23/google-antigravity-2-0-ide-update-gemini-quota-reset/) · [Antigravity Updates - Releasebot](https://releasebot.io/updates/google/antigravity) · [Gemini 한도 9× 누적 (Android Authority)](https://www.androidauthority.com/gemini-antigravity-limits-increased-3670209/) · [I/O 2026 개발자 키노트 (Google Developers)](https://developers.googleblog.com/all-the-news-from-the-google-io-2026-developer-keynote/)
- 🧠 **Claude가 배울 것:** "데스크톱 앱 vs 웹 대시보드" 같은 채널 혼동은 우리 텔레그램 봇과 SSH 터미널 사이에서도 생길 수 있는 패턴 — 진입점 하나에 큰 액션 버튼으로 명확히 라우팅하는 UI 규칙.
- 👤 **내가 알 것:** Antigravity 한도 nerf→9× 회복 완료. Flash가 4× 빠르고 Pro급 → 다이제스트·요약 같은 반복 잡일은 Flash로 코스트 다이어트 검토.

## 🟢 OpenAI / GPT / Codex

**자가개선 세무 에이전트 (Codex)** — OpenAI 엔지니어링 블로그가 **5/27**에 "Building self-improving tax agents with Codex" 공개. 세무 도메인에서 에이전트가 자기 출력을 평가·재학습하며 정밀도를 점진적으로 끌어올리는 패턴.

- 🔗 [ChatGPT Updates - Releasebot](https://releasebot.io/updates/openai/chatgpt) · [ChatGPT 릴리스노트 (OpenAI Help)](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · [GPT-5.5 Instant (OpenAI)](https://openai.com/index/gpt-5-5-instant/) · [OpenAI 뉴스](https://openai.com/news/)

- 👤 **내가 알 것:** GPT-5.5 Instant가 짧고 정확해진 게 핵심 변화. 우리 워크플로엔 "긴 분석" 작업은 여전히 Claude, "빠른 요약"은 5.5/Flash 후보.

## 🧠 메모리 관리 — 논문

**Adaptive Memory Admission Control for LLM Agents (2603.04549)** — 에이전트가 무엇을 메모리에 적극적으로 받아들이고 무엇은 거절할지 **어드미션 정책**을 적응적으로 학습하는 프레임워크. 5/27의 AgeMem(입수제어)과 같은 라인이 굳어지는 중.
- 기존 핵심 서베이도 여전히 유효: **From Storage to Experience (2605.06716)** — Storage→Reflection→Experience 3단계, **Memory for Autonomous LLM Agents (2603.07670)** — write–manage–read 루프 + 5개 메커니즘 패밀리.
- 🔗 [Adaptive Memory Admission Control (arXiv PDF)](https://arxiv.org/pdf/2603.04549) · [From Storage to Experience](https://arxiv.org/abs/2605.06716) · [Memory for Autonomous LLM Agents](https://arxiv.org/abs/2603.07670) · [LTM 보안 서베이](https://arxiv.org/abs/2604.16548)
- 🧠 **Claude가 배울 것:** 우리 `MEMORY.md`는 **모든 입력을 저장**하는 무차별 정책. 어드미션 컨트롤 도입 = "이 메모를 정말 저장할 가치가 있는가?" 게이트 1단계 추가.
- 👤 **내가 알 것:** 메모리 어드미션은 두 달 연속 핫토픽. 우리 vault에도 "입수→정제→추상화" 라이프사이클 명문화할 시점.

## 📓 Obsidian / PKM / 로컬 LLM

**Karpathy식 LLM Wiki, SaaS 현장 ROI 케이스 등장** — 한 SaaS 기업 팀이 **DeepSeek V4**로 Karpathy의 지식 컴파일 방식을 구현해, 매일 Claude Code 세션 로그를 마크다운 위키 엔트리로 플러시하는 스크립트 운영. 결과: **의사결정 속도 +40%, 리워크 -60%**.

- 👤 **내가 알 것:** 우리가 하고 있는 게 ROI 검증된 패턴이라는 외부 데이터 확보(40%/60%). 1주차 회고에 인용할 수 있는 수치.
