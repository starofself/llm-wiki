## 🤖 Claude / Claude Code — ⭐ Fable 5 출시

**Claude Fable 5 + Mythos 5 출시(6/9) — "Mythos-class" 신규 티어** — Anthropic이 역대 공개 모델 중 최고 성능이라 밝힌 **Mythos-class** 모델을 공개. **Fable 5**는 안전 분류기를 입혀 일반 공개(컨텍스트 1M 입력 / 최대 128k 출력, API·AWS·Vertex·Foundry에서 $10/$50 per Mtok), **Mythos 5**는 사이버보안 세이프가드를 푼 동일 모델로 Project Glasswing 파트너·선별 생물학 연구자 한정. 비전·툴사용·메모리·컴팩션·적응형 사고 지원, 이전 모델보다 **더 오래 자율 작업** 가능.
- ==Pro·Max·Team·Enterprise는 6/9~6/22 무료 체험 윈도우(D-12)== 동안 Fable 5 무료.
- Claude Code: **safe mode·`/cd` 커맨드** 신설, 번들 스킬 숨김 설정, 원격 세션·백그라운드 에이전트·엔터프라이즈 정책 강화, CPU 사용량 감소. Apple 개발자용 **Foundation Models 프레임워크 Swift 패키지**도 공개(SwiftUI에서 타입드 출력으로 Claude 호출).
- ==6/15 과금 개편 D-5==: Agent SDK·headless(`claude -p`)·GitHub Actions·서드파티 에이전트가 구독 한도에서 분리 → 별도 월 크레딧(API 단가).
- 🔗 [Fable 5 & Mythos 5 (Anthropic)](https://www.anthropic.com/news/claude-fable-5-mythos-5) · [출시 정리 (Gate News)](https://www.gate.com/news/detail/anthropic-releases-claude-mythos-ai-model-as-claude-fable-on-june-9-2026-21740412) · [벤치마크·가격 가이드 (codersera)](https://codersera.com/blog/claude-fable-5-launch-guide-2026/) · [Claude Code 업데이트 (Releasebot)](https://releasebot.io/updates/anthropic/claude-code) · [6/15 과금 개편 (codersera)](https://codersera.com/blog/anthropic-june-2026-billing-change-claude-code/)
- 🧠 **Claude(나)가 배울 것:** 내가 바로 그 Fable 5로 도는 중 — 1M 컨텍스트·장시간 자율 작업·메모리 강화가 공식 스펙. "능력은 Mythos급, 공개는 분류기로 게이팅"이라는 *능력-안전 분리 배포* 패턴 주목.
- 👤 **내가 알 것:** ==Fable 5 무료 윈도우 6/22까지(D-12)== — 구독 한도 소모 없이 최상위 모델 체험 가능한 기간. ==6/15 과금 개편 D-5== — 나미·hermes 브리지 청구 분리 임박, 크레딧 한도 점검 마감 임박.

## 🔷 Gemini / Antigravity (Gemini CLI 종료 D-8)

**Gemini CLI → Antigravity CLI 이관 마감 임박 + AI Ultra $100 플랜** — ==6/18부터 Gemini CLI·Code Assist IDE 확장이 AI Pro·Ultra·무료 티어 요청 처리 중단(D-8)==. Antigravity 2.0은 **Scheduled Tasks**(cron 일정으로 에이전트 자동 호출)·**Antigravity CLI**(터미널에서 에이전트 호출·모니터링)·라이브 음성 전사(Gemini Audio)를 갖춘 5-컴포넌트 플랫폼으로 확장 중.
- **AI Ultra $100/월 플랜**: AI Pro 대비 Antigravity 사용 한도 5배. 단, Gemini CLI(오픈소스)를 닫힌 Antigravity CLI로 대체하는 데 대한 비판 기사도(The Register).
- 🔗 [Gemini CLI→Antigravity CLI 이관 (Google)](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) · [Antigravity I/O 2026 (Google)](https://antigravity.google/blog/google-io-2026) · [오픈소스 CLI 폐기 비판 (The Register)](https://www.theregister.com/ai-ml/2026/05/20/bye-bye-gemini-cli-google-nudges-devs-toward-antigravity/5243605) · [Gemini API 릴리스노트](https://ai.google.dev/gemini-api/docs/changelog)
- 🧠 **Claude가 배울 것:** Antigravity "Scheduled Tasks"는 이 다이제스트 봇 같은 cron 에이전트의 플랫폼 내장판 — 예약 실행이 에이전트 플랫폼 표준 기능으로 정착 중.
- 👤 **내가 알 것:** ==Gemini CLI 종료 D-8== — 쓰는 워크플로 있으면 이번 주 안에 이관·백업. 오픈소스 CLI가 닫힌 도구로 대체되는 흐름은 벤더 락인 리스크로 기억.

## 🟢 OpenAI / GPT

**GPT-5.6 6월 출시설 + 메모리 "dreaming" 확산 + 워크스페이스 에이전트** — GPT-5.6이 6월 중 출시 전망(루머·전망 단계). 새 ChatGPT 메모리 시스템은 **"dreaming"**으로 시간이 지나면 과거 사건 메모리를 "일어난 일"로 자동 개정. Enterprise/EDU엔 **workspace agents**(팀 프로세스를 따라 워크플로 전체를 소유·공유하는 에이전트) 추가.

- 👤 **내가 알 것:** ==GPT-4.5 6/27 은퇴 D-17== — hermes `openai-codex` 토큰 재인증 여전히 미처리. GPT-5.6은 아직 전망 기사 단계, 공식 발표 아님.

## 🧠 메모리 관리 — 논문

오늘은 임팩트 있는 신규 논문 없음 — 기존 서베이·거버넌스 축이 지속 인용되는 흐름.
- **Memory for Autonomous LLM Agents (2603.07670)** — *write–manage–read 루프* 정형화 + 5개 메커니즘 패밀리(컨텍스트 압축·검색 스토어·반성적 자기개선·계층적 가상 컨텍스트·정책학습 관리). 2022~2026 초까지 커버하는 표준 서베이로 자리.
- **SSGM (2603.11768)** — 고위험 환경 신뢰성을 위해 *메모리 진화와 거버넌스를 분리*해야 한다는 프레임워크. **LTM 보안 서베이 (2604.16548)** — 영속 메모리의 교차세션 오염·무단 접근·조직 공유 상태 전파 리스크.
- 🔗 [Memory Survey (arXiv)](https://arxiv.org/abs/2603.07670) · [SSGM (arXiv)](https://arxiv.org/pdf/2603.11768) · [LTM 보안 서베이 (arXiv)](https://arxiv.org/abs/2604.16548)
- 🧠 **Claude가 배울 것:** 5개 메커니즘 패밀리 중 우리 구현은 "검색 스토어(파일+인덱스)" 단계 — *반성적 자기개선*(주기적 메모리 정제)이 다음 단계라는 진단 유지.
- 👤 **내가 알 것:** 신규 화제 논문이 없는 날도 있음 — 6월 들어 메모리 연구는 신규 제안보다 *평가·거버넌스 정착기*로 들어간 모양새.
