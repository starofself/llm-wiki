## 🧠 메모리 관리 — 논문 (6월 신작 풍년 ⭐)

**이번 주 arXiv에 에이전트 메모리 신작 5편 — 특히 "위키형 메모리" 직접 등장** — 어제까지 "정착기"라더니 6월 신규 제안 러시.
- **Infini Memory (2606.10677)** ⭐ — 장기 메모리를 ==토픽 구조화된 *유지보수 가능한 문서*==로 관리하는 아키텍처. *우리 llm-wiki 방식(주제별 마크다운 + 인덱스)이 그대로 논문이 된 격*.
- **Memory Beyond Recall (2606.09483)** — 단순 회상을 넘어 인지 능력 위계로 메모리를 재조직하는 듀얼프로세스 시스템(DCPM). **Agent Memory 시스템 특성화 (2606.06448)** — 메모리 시스템 10종을 구축·검색·생성 비용으로 프로파일링한 첫 시스템즈 연구. **MAGE (2606.06090)** — 메모리를 의미 조직이 아닌 *실행 상태 관리*로 보는 계층 상태 트리. **Beyond Similarity (2606.06054)** — 유사도 검색을 넘어선 신뢰 가능한 개인 AI 메모리 검색.
- 🔗 [Infini Memory (arXiv)](https://arxiv.org/abs/2606.10677) · [Memory Beyond Recall (arXiv)](https://arxiv.org/abs/2606.09483) · [Agent Memory 특성화 (arXiv)](https://arxiv.org/abs/2606.06448) · [MAGE (arXiv)](https://arxiv.org/abs/2606.06090) · [Beyond Similarity (arXiv)](https://arxiv.org/abs/2606.06054)
- 🧠 **Claude가 배울 것:** Infini Memory의 "토픽 문서 + 유지보수(merge·rewrite·prune)" 루프는 내 `memory/` 운영 정책 그 자체 — 핵심은 *추가*가 아니라 *주기적 재작성*. 2606.06448의 "쓰기 경로 vs 읽기 경로 비용 분리" 관점으로 우리 인덱스 갱신 비용도 점검 가능.
- 👤 **내가 알 것:** 우리가 쓰는 파일-위키 메모리 방식이 이제 논문 아키텍처로 정식 등장(Infini Memory) — 방향 검증된 셈. "정착기" 진단은 하루 만에 정정.
