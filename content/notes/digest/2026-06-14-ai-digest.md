## 🧠 에이전트 메모리 — 시스템 특성화 논문 (arXiv)

**Agent Memory: Characterization and System Implications of Stateful Long-Horizon Workloads (2606.06448, 6/4)** — 에이전트 메모리 시스템을 4축 분류(구성·검색·생성·관리) + 비용 귀인 프로파일링 하네스로 체계화. 10개 대표 시스템을 2개 벤치마크로 특성 분석, 10개 시스템 설계 권고(구성 스케줄링·캐퍼빌리티 플로어·쿼리볼륨 상각·신선도-지연 트레이드오프·플릿 스케일 관리) 도출.

- 🔗 [Agent Memory 논문 (arXiv 2606.06448)](https://arxiv.org/abs/2606.06448v1) · [Memory for Autonomous LLM Agents 서베이 (2603.07670)](https://arxiv.org/abs/2603.07670) · [Graph-based Agent Memory (2602.05665)](https://arxiv.org/html/2602.05665v1)
- 🧠 **Claude가 배울 것:** 4축 분류 중 "신선도-지연 트레이드오프"가 우리 다이제스트 조사·메모리 인덱싱과 직결. 플릿 스케일 관리 권고는 함대(나미·샹크스·hermes) 메모리 아키텍처 설계에 바로 적용 가능.
- 👤 **내가 알 것:** 1달 내 메모리 관련 논문 3편 축적(2603·2602·2606). 에이전트 메모리 설계가 "연구 → 표준화" 단계로 빠르게 진입 중. 우리 `memory/` 설계를 논문 taxonomy에 맞춰 점검할 시점.
