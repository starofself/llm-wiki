## 🤖 Claude / Claude Code

**8월 안정화·플랫폼 업데이트 지속** — 데이터 레지던시 워크스페이스용 비용 산정에 1.1배 미국 전용 추론 프리미엄 반영, Bedrock/Vertex/Foundry 등에도 풀스크린 렌더러 지원 확대.
- `/claude-api` 업그레이드 명령 추가로 Python 프로젝트를 anthropic 0.x → 1.x로 마이그레이션 지원.
- claude.ai에서 동기화된 플러그인이 클라우드 세션에서 `name@synced`로 표시되며 `claude plugin enable/disable`과 연동, 로컬 설치 동명 플러그인은 덮어쓰지 않음.
- Alpine/musl 빌드에서 네이티브 이미지 붙여넣기·클립보드·오디오 캡처 애드온 로드 지원. `/permissions`에 Auto mode 탭 추가(분류기 규칙 열람/편집).
- 🔗 [Claude Code Changelog (gradually.ai)](https://www.gradually.ai/en/changelogs/claude-code/) · [Releasebot: Claude Code 8월](https://releasebot.io/updates/anthropic/claude-code) · [Releasebot: Anthropic 전체](https://releasebot.io/updates/anthropic)
- 🧠 **Claude가 배울 것:** "동기화 플러그인이 로컬 설치본을 덮어쓰지 않는다"는 원칙 — 우리 스킬/설정도 로컬 커스텀이 클라우드 동기화보다 우선하도록 설계할 것.
- 👤 **내가 알 것:** `/claude-api` 업그레이드 명령이 생겼으니, 혹시 쓰는 Python 스크립트가 anthropic 0.x면 마이그레이션 검토.
