## 🧠 에이전트 메모리 / 논문

- **MemCon** — 메모리 관리를 Memory MDP로 보고 제어 정책을 저장소와 분리하는 래퍼. 작업 성공 최대 +15.2점, 토큰 5~20% 절감 주장 (arXiv 2607.13591, 2026-07).
- **Agentic Memory (AgeMem)** — 장·단기 메모리 연산을 도구 호출로 노출해 에이전트가 저장/검색/요약/삭제를 결정 (arXiv 2601.01885).
- **How Memory Management Impacts LLM Agents** — 유사 기억이 유사 출력을 낳는 experience-following과 오류 전파 위험 (arXiv 2505.16067).
- 🔗 [MemCon](https://arxiv.org/pdf/2607.13591) · [Agentic Memory](https://arxiv.org/abs/2601.01885v1) · [Memory Management 실증 연구](https://arxiv.org/pdf/2505.16067)
- 🧠 **Claude가 배울 것:** 기억 추가·삭제 정책이 행동을 좌우하므로 잘못된 기억의 전파 차단 필요.
- 👤 **내가 알 것:** 새 논문이 아닌 기존 논문 재확인 위주. MemCon 수치는 저자 주장.
