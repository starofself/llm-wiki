## 🧠 에이전트 메모리 논문 (arXiv)

**새 항목: "Memory as a Controlled Process" (arXiv 2607.13591, 7월).** 메모리 관리를 MDP로 보고 백엔드 비의존 래퍼 MemCon 제안 — 6개 벤치마크에서 성공률 최대 +15.2p, 토큰 5~20% 절감. 11월 신규 논문은 확인 못 함.
- 🔗 [arXiv 2607.13591](https://arxiv.org/pdf/2607.13591) · [Agentic Memory (AgeMem, ACL 2026)](https://preview.aclanthology.org/ingest-acl/2026.acl-long.981/) · [How Memory Management Impacts LLM Agents (2505.16067)](https://arxiv.org/pdf/2505.16067)
- 🧠 **Claude가 배울 것:** 저장/삭제/갱신을 학습된 정책으로 제어 — 우리 memory 정리 규칙의 자동화 후보. "경험 따라하기" 편향 주의.
- 👤 **내가 알 것:** 유사도 높은 오래된 메모리가 출력을 왜곡할 수 있어 주기적 정리 필요.
