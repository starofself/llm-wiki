① Vault 폴더 만들기

mkdir my-vault && cd my-vault

mkdir: 폴더 생성  /  cd: 작업 디렉터리 이동  /  &&: 앞 명령 성공 시 다음 실행

시연 후 학습자에게 `pwd` 결과를 채팅에 한 줄 붙이라고 요청. `/Users/홍길동/Desktop/my-vault` 같이 명확한 분만 다음 단계로. 터미널 기본기 부족한 분은 휴식 시간(55–65분)에 보조.

② 그 폴더에서 Claude Code 켜기

claude

claude: 현재 폴더에서 Claude Code 실행  /  켠 자리 = Claude가 vault로 인식하는 폴더

방금 만든 my-vault/ 폴더로 이동한 상태에서 `claude` 실행. 핵심 한 마디 — "어디서 켜느냐 = Claude가 어느 폴더를 vault로 인식하느냐". 다른 폴더에서 켜면 그 폴더가 vault가 됨. 학습자 화면 확인: 프롬프트 표시가 my-vault 안인지.

Q1

프론트매터를 왜 굳이 쓰나요?

사람과 코드가 같이 읽는 메타정보를 한 파일에 두는 가장 가벼운 방법.

사람이 읽는 글(본문)과 코드가 읽는 메타정보(태그·날짜·관계)를 한 파일에 같이 두는 가장 가벼운 방법. 이게 있어야 2주차 봇·3주차 API가 노트를 분류·검색할 수 있다.

인덱스 키워드 10개 어떻게 정하나요?

이미 머릿속에서 자주 쓰는 분류 그대로 — 새로 만들지 마세요.

Q3

결국 1주차에 한 게 뭐죠?

Vault 구축. 2~4주차에 이 위에 사용자 UI · 시스템 UI · 표준 UI를 한 겹씩 추가.

Q5

Vault를 GitHub에 올려도 되나요?

private 리포면 가능. 단, 프론트매터에 비밀 키 적지 마세요(.env로).
